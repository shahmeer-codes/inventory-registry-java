# 📦 Inventory Registry

A console-based Java inventory management application built to practice **ArrayList**, **Java Collections Framework**, and **menu-driven programming**. The application allows users to manage a simple inventory by adding, viewing, searching, sorting, removing, counting, and clearing items.

---

## ✨ Features

* Add multiple inventory items
* View all inventory items
* Search for an item
* Remove an item
* Sort items alphabetically
* Count total items
* Clear the inventory
* Interactive menu-driven interface

---

## 🛠️ Technologies Used

* Java
* Java Collections Framework (`ArrayList`, `Collections`)
* Scanner Class

## 🚀 How to Run

1. Clone the repository.
2. Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse, VS Code, etc.).
3. Compile and run `Main.java`.
4. Use the interactive menu to manage the inventory.
